# javascript-basics-ararat-folks

> Cover some Basic Concepts of JavaScript.

An interactive visualization of the JavaScript **Event Loop**, **Call Stack**, **Web APIs**, **Macrotask Queue**, and **Microtask Queue**.

## Run locally (recommended)

Requires [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev
```

Open **http://localhost:5173** in your browser. Vite serves `index.html` with `src/main.js` and `src/styles.css` — edits hot-reload as you work.

### Other scripts

| Command | Purpose |
|---------|---------|
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Serve the production build locally |

## Project layout

```
index.html          # page markup
src/main.js         # simulator logic
src/styles.css      # styles
```

## Tips

- Open DevTools with **⌘ + ⌥ + I** while using the simulator.
- Hard-reload with **⌘ + ⇧ + R** if the page looks stale.
